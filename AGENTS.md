## Agent skills

### Issue tracker

Use GitHub Issues in `bliu217/sentinel`. Read `docs/agents/issue-tracker.md`
before reading, creating, or updating tickets.

### Delivery workflow

Read `docs/agents/delivery-workflow.md` before starting implementation,
choosing a branch, preparing a PR, or deciding whether an issue is complete.

### Triage labels

Use the five default triage labels. Read `docs/agents/triage-labels.md`
before triaging issues.

### Domain docs

Use a single-context layout. Read `docs/agents/domain.md`
before exploring the codebase.
